# BCH Flow — The Pix Experience for Bitcoin Cash

Send · Receive · Request · Pay. Familiar payment UX with BCH mainnet settlement.

**Not Pix integration.** BRL amounts are reference quotations only; no BRL bank settlement is promised.
**Noncustodial.** Signing happens in the user's compatible wallet.
**Human-readable aliases.** BCH Flow aliases are application-local, not native BCH identities.
**Never conflate** observed, unconfirmed and confirmed blockchain transactions.
